# 🫠 وش الرياكشن؟ | AI Reaction Finder

اوصف الموقف بكلامك وبلهجتك.. والذكاء الاصطناعي يفهم شعورك ويلقى لك الرياكشن المناسب من الميمز والـ GIFs المشهورة في السوشل ميديا، ويقترح لك تعليق تنشره معه.

> Describe a situation in Arabic, and AI finds the perfect reaction GIF from GIPHY — plus a funny caption to post with it.

---

## ✨ المميزات

- ✍️ **وصف بالعامية**: اكتب الموقف زي ما تقوله لصاحبك
- 🧠 **الذكاء يفهم الشعور**: يحوّل وصفك لـ 4 كلمات بحث مختلفة (مصدوم، ضحكة محرجة، facepalm...) وتتنقل بينها بضغطة
- 🎞️ **رياكشنز حقيقية من GIPHY**: نفس الـ GIFs والميمز اللي يستخدمها الناس في السوشل ميديا
- 💬 **تعليق مقترح** بنفس لهجتك مع زر نسخ
- 🇸🇦 **رياكشنات عربية**: وضع عربي (افتراضي) يبحث في الميمز الخليجية والمصرية والعربية، أو وضع عالمي
- 🏷️ **GIF أو ستكرز**
- 🔥 **الرائج الآن** يظهر أول ما تفتح الموقع
- 📤 **مشاركة مباشرة** من الجوال، أو نسخ الرابط
- 🕘 **آخر 5 عمليات بحث** محفوظة
- 📱 متجاوب مع الجوال ويدعم العربية بالكامل

## ⚙️ كيف يشتغل؟

```
وصف المستخدم (عربي)
        │
        ▼
 نموذج ذكاء (Pollinations) ──► JSON: { queries[4], caption }
        │
        ▼
 GIPHY Search API ──► شبكة رياكشنز ──► معاينة ← مشاركة / نسخ رابط
```

بدون مفتاح ذكاء، الموقع يستخدم قاموس داخلي للهجة السعودية (30+ موقف) مع ترجمة تلقائية، وإذا كلمة ما جابت نتائج ينتقل للي بعدها تلقائياً.

## 🛠️ التقنيات

- HTML + CSS + JavaScript (ملف واحد، بدون مكتبات)
- [GIPHY API](https://developers.giphy.com) للبحث والرائج
- [Pollinations.ai](https://pollinations.ai) لفهم الوصف واقتراح الكلمات والتعليق
- localStorage للمفاتيح وآخر بحث
- Web Share API + Clipboard API

## 🚀 التشغيل

1. **مفتاح GIPHY (مطلوب):** من [GIPHY Developers](https://developers.giphy.com/dashboard/) ← Create an App ← API ← انسخ المفتاح (مجاني، 100 بحث بالساعة)
2. **مفتاح Pollinations (اختياري):** من [enter.pollinations.ai](https://enter.pollinations.ai/keys) خذ مفتاح عام يبدأ بـ `pk_` وحط له حد ميزانية
3. افتح الموقع ← ⚙️ ← ألصق المفاتيح

**اختياري:** عشان الزوار ما يحتاجون إعدادات، حط مفاتيحك في `index.html`:

```js
const DEFAULT_GIPHY_KEY = '...';
const DEFAULT_POLLI_KEY = 'pk_...';
```

> ⚠️ لا تحط مفتاح `sk_` السري في الكود أبداً.

## 🌐 النشر على GitHub Pages

1. ارفع الملفات في مستودع جديد
2. Settings ← Pages ← Branch: `main` ← Save
3. بعد دقيقة يصير الموقع على: `https://<username>.github.io/reaction-finder/`
